# Sample Form Repository

A small collection of sample forms for **Lala Companies**, because apparently asking people for their name, email, and phone number still requires a repository.

## What's Inside

* Directly sends to Whatsapp/Email log
* Clean & reusable form template
* Basic validation
* Sensible structure
* Minimal dependencies
* Enough documentation to prevent unnecessary changes

## Usage

Clone the repository, pick this form, customize the fields and pretend this was the obvious solution all along.

```bash
git clone <repository-url>
cd <repository-name>
```

Open the relevant HTML file in a browser. No backend required.

## Customization

Modify the fields, labels, validation rules and styling as needed. The forms are intentionally simple, so they can be adapted without consulting a committee. Especially to help the save their time opening any CRM or Excels.

## Note

These are sample forms, not a declaration of architectural philosophy.

Built for **Lala Companies**.
